🍽️ Restaurant HTML Project

A modern and responsive luxury hotel-themed single-file HTML project created to showcase frontend design skills, clean layouts, and attractive UI elements using pure HTML, CSS, and JavaScript.

⸻

✨ Features

* Responsive design for mobile, tablet, and desktop
* Modern restaurant landing page
* Interactive navigation bar
* Beautiful food sections and menu showcase
* Smooth scrolling animations
* Contact section with location details
* Fast and lightweight UI
* Attractive and user-friendly layout

⸻

🛠️ Tech Stack

* HTML5
* Embedded CSS
* Embedded JavaScript
